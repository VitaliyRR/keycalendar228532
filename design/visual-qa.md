# Проверка дизайн-комплекта

Дата: 24.09.2026. Статус: статичные материалы подготовлены и осмотрены. Проверка не подтверждает работоспособность будущего приложения, browser reflow или соответствие WCAG целиком.

## Покрытие

- 77 канонических экранов, 6 общих состояний, 20 предметных вариантов, 4 адаптивных листа и библиотека компонентов: **108 SVG и 108 PNG**.
- 77 контрактов экранов связаны с требованиями и правилами состояний. 152 готовых текста с проверяемыми placeholders.
- Все PNG отрендерены локальным resvg с предоставленным Golos Text; скриншоты реального аккаунта не использованы.
- Просмотрены пять контактных листов и отдельно полноразмерные ключевые макеты: календарь/карточка/создание/отмена, публичная оплата, migration dry-run, платежи/залоги, настройки доступа, аудит, цена, конфликты, компоненты, mobile и регистрация.
- Геометрия всех текстовых узлов и 10 семантических цветовых пар проверены скриптом. Выходов текста за границы артборда нет; все проверенные пары обычного текста имеют контраст ≥4.5:1. Это не автоматическая проверка любых пересечений элементов или интерактивного фокуса.

Сводный [машинный результат](review/geometry-and-contrast.json). Контактные листы: [1](review/contact-01.png), [2](review/contact-02.png), [3](review/contact-03.png), [4](review/contact-04.png), [5](review/contact-05.png).

## Исправления по результатам осмотра

| Находка | Исправление |
|---|---|
| Кнопки перехода периода могли пересекаться; символ стрелки зависел от глифа | Явная ширина кнопок; chevron нарисован вектором |
| Разные разделы нуждались в своих композициях | Отдельные макеты публичного оформления, кабинета гостя, документов/договора, уведомлений, сверки/переключения, счетов подписки |
| Черновик новой брони показывал существующий платёж/историю | Оплачено0, остаток12600, оплата только после создания; явные действия подтверждения и заявки |
| Просрочка могла читаться как остановка всех входящих событий | Входящие брони/платежи и аварийное закрытие продолжаются; новые продажи/правки ограничены |
| Конфликт мог обещать уже подтверждённый stop-sell всех OTA | Указаны локальное закрытие и отдельное подтверждение каналов в журнале |
| Визуально не хватало платёжной ссылки и авторизации залога | Добавлены VAR-FIN-LINK и VAR-FIN-AUTHORIZATION с суммой/сроком/режимом и отдельным release |
| Офлайн требовал конкретного безопасного состояния | VAR-CAL-OFFLINE без гостевых контактов, сумм, документов и кодов, с давностью и запретом записи |
| Отмена требовала видимого финансового расчёта | Показаны начисления после отмены, штраф, оплата, переплата и доступный отдельный возврат |
| Экран счетов был без обратной связи с требованием | SCR-BILL-03 связан с REQ-BILL-002, его задачей и проверкой |
| Целевой p95 расходился с архитектурой | На OPS-01 установлено800мс; указано, что это цель, не измерение |

## Что проверяется при реализации

Клавиатура/диктор, focus trap/return, масштабирование, реальные hit areas, виртуализация на1000объектов, конкурентные команды, загрузка/таймауты, актуальность разрешений, реальная доставка/оплата, работа responsive в браузере и юридические тексты. Эти проверки перечислены в [specification.md](specification.md) и [плане тестирования](../plan/testing.md), статичные PNG их не заменяют.

Для внесения правок редактировать SVG либо исходные композиции, затем синхронно обновить PNG и контракты. Предпочтительно менять генератор, чтобы последующая сборка сохраняла исправления. Не использовать реальные данные для «более правдоподобных» макетов.
