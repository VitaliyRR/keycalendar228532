# Данные для проектирования и переноса

В Git находятся только схема, синтетические примеры и процедура проверки. Реальная выгрузка, нормализованные строки и manifest первого заказчика находятся в отдельном закрытом каталоге вне репозитория; путь и доступ передаются владельцу приватно. Не добавлять сюда даже зашифрованный production dump: ошибка управления ключами и копии Git усложняют контроль хранения.

- [Спецификация переноса](migration-spec.md): достоверность источника, соответствие полей, dry-run, сверка и переключение.
- [Фактический формат закрытого набора](seed-format.md): envelope этапа 0 и соответствие будущему staging этапа 1; текущий seed ещё не является готовым импортом.
- [Схема staging](staging.schema.json): структура промежуточной записи с provenance и uncertainty.
- [Синтетические сценарии](synthetic-scenarios.json): только искусственные данные для дизайна и будущих проверок.
- [Шаблон сверки](reconciliation-template.csv): поля для отчёта, без реальных количеств и сумм.

Полученный безопасный экспорт является частичным источником. Он не содержит полного журнала оплат, состояния каждой брони и стабильных ID. Наличие файла не означает готовность промышленной миграции.
