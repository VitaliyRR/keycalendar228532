# Формат сохранённого закрытого набора

В этой работе подготовлен **этап 0: неизменный источник и опись строк**. Файл `bookings-staging.jsonl` в закрытом каталоге не объявляется уже приведённым к [staging.schema.json](staging.schema.json). Эта схема задаёт **этап 1 будущего миграционного процесса**, после добавления package metadata, candidate и решений проверки. Ни этап 1, ни импорт в рабочую организацию ещё не выполнены.

Закрытый путь хранится у владельца отдельно от Git. Публичные материалы содержат только формат и имена полей, не значения, объём, ID реальных объектов или хэш клиентского файла. Полная [спецификация переноса](migration-spec.md) остаётся обязательной.

## Что фактически сохранено

| Файл | Назначение |
|---|---|
| bookings.xls | Оригинальная штатная выгрузка. Несмотря на расширение, XML Spreadsheet 2003; файл не менялся. |
| bookings-staging.jsonl | По одной записи на физическую строку источника; только provenance, raw source_values и неизвестные доменные значения. |
| manifest.json | Дата/контрольная сумма/колонки/качество и границы полноты; реальные результаты приватны. |
| inventory-ui.json | Опись увиденных объектов и подписей каналов; это выборка интерфейса, не полный экспорт модели. |
| account-profile.private.json | Наблюдаемые структуры и процессы без сохранённых паролей/кодов синхронизации. |
| source-distribution.private.json | Закрытая группировка источников/объектов/менеджеров для сверки. |
| README.md | Область разрешённого использования, ограничения, локальный доступ. |

Файлы наблюдений интерфейса в том же каталоге вспомогательные и приватные. Наличие подписи канала не доказывает работоспособность соединения. Секретные значения кодов/ссылок доступа не являются данными миграционной модели и исключены из материалов.

## Envelope этапа 0 → этап 1

| Ключ существующей строки | Тип / смысл | Поле планируемой схемы |
|---|---|---|
| staging_row_id | string, идентификатор только строки данного снимка | source_locator, с явным namespace package |
| source_file_sha256 | string, хэш оригинальной выгрузки | source_checksum |
| source_row_number | integer, строка источника | row_number |
| source_values | object, девять исходных колонок без доменной интерпретации | raw по таблице ниже |
| source_reservation_id | null, источник не дал ID | Evidence/ImportRecord: заполнить после подтверждённого обогащения, не добавлять произвольное поле в candidate |
| target_reservation_id | null, импорт не выполнен | Создаётся после apply и сохраняется в source-target map; не требуется для этапа1 |
| review_status | string, не проверено | disposition = staged либо quarantine по ошибкам; candidate.identity_confidence = unreviewed |
| currency | null | candidate.currency = null до доказательства |
| reservation_status | null | candidate.status = unknown, без назначения confirmed |
| payment_history | null | missing dataset, отдельная проверка; не выдумывать Payment |
| warnings | array, структурные замечания | review_flags[] с нормализованными кодами |
| Нет в этапе0 | package ID, название листа | package_id и worksheet берутся из манифеста/оригинального XML на этапе1 |

Имена candidate в текущей [JSON Schema](staging.schema.json) должны применяться буквально при реализации. Строка этапа0 не проходит validation этой схемы напрямую; будущий transformer сначала конструирует разрешённые поля. Если нужного поля нет в candidate schema, хранить evidence в ImportRecord/report, не отключать additionalProperties=false.

| Исходная колонка source_values | raw схемы этапа1 |
|---|---|
| Объект | object_label |
| Заезд | checkin |
| Выезд | checkout |
| Контакты | contacts |
| Примечания | note |
| Гостей | guests |
| Сумма | amount |
| Источник | source_label |
| Менеджер | manager_label |

Трансформация read-only относительно источника, decimal/date parsing после сохранения raw; неизвестные значения остаются неизвестными. SpreadsheetML может содержать разреженные ячейки с `ss:Index`: позицию нельзя определять простым порядком XML-элементов. Формулы/ссылки не исполняются. Полноту и связность нельзя вывести из совпадения количества строк.

## Критерий будущего продвижения

Перед этапом1 проверить хэш исходника и качество разбора, сформировать package_id/worksheet, нормализовать raw и записать ошибки. Перед apply закрыть ID/статусы/валюты/объекты, получить отдельный набор финансов либо утверждённые начальные остатки с явно ограниченной историей. Ни один этап не может сделать все строки активными или считать сумму брони уже полученными деньгами.
